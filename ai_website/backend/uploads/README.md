# Prompt Suggestion System (C + Python Project)

This is a **Major Project** for engineering final year students.  
The system generates intelligent **prompt suggestions** based on any user query.

It uses:

- **C (UI Layer)** – terminal user interface (`ui.c`)
- **Python Backend** – executes model and returns results (`python_backend.py`)
- **Python AI Model** – semantic similarity model (`model.py`)
- **Prompt Bank** – stored in `prompts.py` (no JSON file used)
- **Sentence Transformers** – AI embeddings for understanding meaning
