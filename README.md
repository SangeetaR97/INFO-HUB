# AI Info Hub

AI Info Hub is an AI-powered web application that provides multiple
AI-based utilities in one platform.

## 🚀 Features

- AI Learning Assistant
- AI Chat
- Prompt Suggestion System
- Audio to Text
- Text to Audio
- PDF to Audio
- Mental Health Analysis
- AI Tools 

## 🛠️ Technologies

- Python
- Flask
- JavaScript
- HTML
- CSS
- Machine Learning
- NLP
- Gemini API

- Scikit-learn

## ⚙️ Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/SangeetaR97/INFO-HUB.git
   ```

2. Navigate to the project folder:

   ```bash
   cd INFO-HUB
   ```

3. Create and activate a virtual environment:

   ```bash
   python -m venv venv
   ``` 

   **Windows:**

   ```powershell
   venv\Scripts\activate
   ```

4. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

## ▶️ How to Run

1. Navigate to the `ai_website` folder:

   ```powershell
   cd ai_website
   ```

2. Start the Flask backend:

   ```powershell
   python app.py
   ```

3. Open the application using the configured local server.
